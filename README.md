## 簡報特色

- **一頁一重點**：每張投影片左欄講透一個核心觀念或題型，右欄提供動態視覺圖解或互動探究。
- **豐富動態互動**：全冊 11 處動態滑桿與步驟推理（區間端點滑桿、交集文氏圖、量詞否定步驟、含參二次不等式拋物線、均值幾何模型、對稱軸滑動最值、二分法折半逼近、對勾函數等）。
- **完整例題與解答**：每頁均附帶考點範例與詳細推導步驟，點擊右上角可滿版全螢幕放大。
- **易錯防坑對照**：每節均提供常見錯誤（✗）與規範正解（✓）表格。
- **課堂授課教具**：內建雷射筆、彩色畫筆、橡皮擦與全螢幕投影功能。
